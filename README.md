# CampingChecklist

### Camping Trip Checklist

A Java desktop application for organizing camping trip packing lists and tracking packing progress.

## Planned Features
- Create and manage trips.
- Add, edit, and remove packing items.
- Mark items packed or unpacked.
- View packing progress.
- Save and load trips and packing lists.
